# Credits and rights checklist

**Before publishing:** confirm that the existing author line and MIT license in `LICENSE` are correct for the code you are entitled to publish. Keep third-party attribution where required. Generated or assisted code must not be represented as entirely hand-written if that would be misleading in your application.

The project uses existing standard algorithms (dynamic programming and formal graph search). Research docs and examples cite external music-encoding and computational-musicology literature where used. The UI and data are exploratory and do not imply endorsement by the authors of external datasets.

**Do not add** your application essays, grades, dates of birth, phone number, address, private academic records, API keys, private reviewer data or raw copyrighted song recordings to this repository. If you add original score data later, verify the upstream license and cite the source.
