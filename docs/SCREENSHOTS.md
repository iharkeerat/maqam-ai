# Adding genuine screenshots (optional)

No screen capture has been fabricated for this portfolio. If the Next.js UI runs on your machine:

1. Open `http://localhost:3000` and capture the home workbench.
2. Open `http://localhost:3000/alignment-lab` and capture the constructed formal demo showing both inputs and output.
3. Crop away browser tabs, local file paths and any personal information.
4. Save files as `docs/assets/workbench.png` and `docs/assets/alignment-lab.png`.
5. Add the Markdown references to `README.md` only after inspecting your **actual** screenshots.

Screenshots should be real application output, not AI-generated interface mockups.
