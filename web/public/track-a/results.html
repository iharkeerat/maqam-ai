Key empirical result

For single-lock edits, A2 consumed 0.63× the total full-DAG time (cluster bootstrap 95% interval 0.593–0.667). For wide edits, A2 consumed 1.67× the full-DAG time (1.617–1.718). Ratios describe sums, not medians.

What is—and is not—new?

All three methods maintain the same shortest-path optimum on a fixed acyclic graph. Incremental shortest-path methods already exist in published work. This is a benchmarked engineering trade-off, not an established original algorithm or real-world song-alignment result.

Interpreting the experiment
  • The formal input consists of constructed syllable symbols, rhythm-event lengths, and edit locks—not independently annotated singing.
  • The dynamic baseline independently uses a g/rhs priority queue in an LPA*-style specialization, not the authors' optimized LPA* source code.
  • Absolute Python microbenchmark timings depend on machine, runtime and measurement conditions. The frozen task-file SHA-256 permits exact task verification.
  • Only lock-only edits on unchanged graph geometry were evaluated. The research has not established broader edit support.
